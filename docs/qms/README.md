# braumm 품질경영시스템(QMS) 규정집

braumm의 품질경영시스템(Quality Management System) 문서를 관리하는 디렉터리입니다.
아직 ISO 9001 인증(등록) 전 단계로, 인증 준비 및 사내 품질관리 기준 확립을 위해
ISO 9001:2015 요구사항을 기반으로 규정을 순차적으로 정비합니다.

- **회사**: braumm (2026. 03. 09 법인 설립)
- **적용표준**: ISO 9001:2015
