# 변경 이력

프로그램 판 번호는 `도움말 → 프로그램 정보` 와 창 제목에서 볼 수 있습니다.
기능을 더할 때마다 0.1 씩 올라갑니다.

---

## v1.2  (2026-09-04)

- **명판(Name Plate)** 항목 추가 — 값을 적으면 명판 도안 위에 찍힌다.
  · 명판 도안(바탕 그림)을 [첨부 도면] 에 넣으면 그 위에 값만 인쇄
  · 넣지 않으면 테두리 + 로고 + 제조사 표기를 그려 기본 명판을 만든다
  · 라벨을 비우면 제목 줄, 크기배율로 줄마다 글자 크기 조절
  · `{제품명}` `{도번}` `{리비전}` 같은 자동 입력 항목 사용 가능
  · 줄이 많아 넘치면 글자 크기를 자동으로 줄여 도안 안에 맞춘다
  · [배치] 탭에서 글자 위치·크기를 % 로 조절
- 자재 리스트에 **제조사 / Manufacturer** 열 추가 (총 7열)
- 해당 없는 인증 칸은 비워 두거나 N/A 로 적는다는 안내 추가

## v1.1  (2026-09-04)

- **자유 표** 항목 종류 추가 — 열 이름과 열 수를 직접 정할 수 있다.
  기존 사양표(항목/사양/비고 3열)로는 못 만들던 표를 만들 수 있다.
- **자재 리스트 / Materials List** 추가
  (No. / 품명 / 사양 / UL File No. / RoHS / MSDS, 14줄)
- **구조 및 부품 / Construction and Parts** 추가 — 외형도 풍선 번호와 짝을 이루는 부품 목록
- 기본 사양에 전기 특성 보강 — 리플 전류, 직류 저항, 총 손실, 과부하 용량, 온도 상승, 소음
- 새 항목들은 **생산 + 고객** 으로 기본 설정 (필요하면 생산용만/고객용만 으로 바꿀 수 있음)
- 자유 표도 **줄 단위로 고객에게 감출 수 있음**
- 누출 검사를 자유 표 칸까지 확대하고, 공백을 무시해 비교하도록 강화
  (좁은 칸에서 줄바꿈된 글자도 잡힌다)

기존 문서는 `도구 → 최신 템플릿의 추가 항목 가져오기` 로 새 항목을 받을 수 있습니다.

## v1.0  (2026-09-04)

첫 판 번호를 붙인 판입니다. 이번에 더한 것과, 여기까지 만들어진 기능을 정리합니다.

**이번에 더한 것**
- 판 번호 체계 도입 (창 제목 · 도움말 → 프로그램 정보 · exe 파일 이름)
- 승인 사양서의 정형 문구(적용 규격 · 허용 공차 · 시험 항목 …)를
  문서 안에서 직접 고치고 줄을 더할 수 있게 함
- 승인란을 [도장] [이름] [일자] 고정 높이 행으로 바꿔,
  도장이 없어도 이름 크기와 칸 높이가 흔들리지 않게 함
- 승인 사양서 매 장 오른쪽 위에 회사 로고

---

### 여기까지 만들어진 기능

**문서 만들기**
- 사양 값과 도면을 넣으면 A4 도면 양식의 생산 사양서 PDF 생성
- 항목 번호(1. 2. 3. …)와 `PAGE n / N` 자동 채번
- 표지 (로고 · 제품명 · 고객사 · 도번 · 리비전 · 승인란), 쪽 번호에서 제외
- 모든 항목에 표 + 도면을 함께 넣을 수 있음
- 도면 폭 `0` = 지면에 맞춰 최대, 회전 `90` 으로 가로 도면을 크게

**고객 승인 사양서**
- 저장 한 번에 생산 사양서와 고객 승인 사양서를 동시 발행
- 항목별 공개 범위(기본값 `생산용만`)로 민감 내용 차단
- 승인 사양서는 영문 문서체 + 고객 승인란

**도번 · 리비전**
- `BR-제품군-고객코드-정격전류-일련번호` 자동 발급, 도번 대장 관리
- 리비전 A → B → C, 개정 이력 자동 기록

**편집**
- 표마다 “선택한 행 입력” 패널, 엑셀 붙여넣기
- `{고객사}` `{도번}` 등 자동 입력 항목
- 최신 템플릿의 추가 항목 가져오기 (예전 문서도 업데이트 반영)
- 승인란에 도장 · 사인 이미지

**신뢰성**
- 예전 문서 호환 보장 (얼려 둔 fixture 로 매 빌드 검증)
- 고객 문서 누출 검사 등 자체 점검 25항목
