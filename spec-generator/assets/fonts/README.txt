여기에 TTF/OTF/TTC 폰트 파일을 넣어두면 PDF 생성 시 가장 먼저 사용합니다.
(예: NotoSansCJKkr-Regular.otf, malgun.ttf)

넣지 않으면 프로그램이 아래 순서로 시스템 폰트를 자동으로 찾습니다.
  Windows : NotoSansCJKkr → 맑은 고딕 → 메이리오 → Yu Gothic → MS Gothic
  macOS   : Apple SD Gothic Neo → Arial Unicode
  Linux   : Noto Sans CJK → 나눔고딕 → WenQuanYi

일본어와 한글이 함께 들어가는 문서라면 Noto Sans CJK 를 넣어두는 것을 권합니다.
파일 이름에 "Bold" 가 들어간 폰트는 굵은 글씨용으로 자동 인식합니다.
