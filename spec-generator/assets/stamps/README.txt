도장 · 사인 이미지를 두는 곳입니다.

  파일 이름을 "이름.png" 로 두면 그 사람의 승인란에 자동으로 찍힙니다.
      예)  홍길동.png,  김철수.png,  박영희.png

  · PNG 배경 투명 권장 (JPG 도 되지만 흰 사각형이 같이 찍힙니다)
  · 정사각형에 가까운 도장이면 300x300px 정도면 충분합니다
  · 문서마다 다른 도장을 쓰려면 ① 기본정보에서 파일을 직접 지정하면 됩니다
  · 문서 폴더 안의 stamps/ 폴더도 같은 방식으로 찾습니다

★ 주의 — 도장·사인 이미지는 서명과 같은 효력을 가질 수 있습니다.
  이 폴더의 이미지 파일은 git 에 올라가지 않도록 .gitignore 에 넣어 두었습니다.
  공유 폴더에 둘 때도 접근 권한을 확인하세요.
