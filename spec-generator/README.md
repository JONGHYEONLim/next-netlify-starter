# Braumm 생산 사양서 생성기

사양 값과 도면을 넣으면, 생산 현장에 그대로 넘길 수 있는 **A4 도면 양식 사양서 PDF** 를
만들어 주는 데스크톱 프로그램입니다.

- PDF 첫 장에 **로고가 들어간 표지**가 붙습니다 (끌 수 있음, 쪽 번호에서는 제외)
- 승인란에 **도장 · 사인 이미지**를 찍을 수 있습니다 (`assets/stamps/이름.png` 로 두면 자동)
- **고객 승인 사양서**가 같이 발행됩니다 — 턴수·갭 같은 민감 내용은 빠진 영문 문서
- 항목 번호(`1.` `2.` `3.` …)와 `PAGE n / N` 은 **자동으로 다시 매겨집니다**
- 사양표는 **엑셀에서 복사 → 붙여넣기** 로 한 번에 채웁니다
- 항목 하나에 **표 + 도면을 함께** 넣을 수 있습니다 (예: 요크코어 사이즈 + 도면)
- 도면은 **PNG / JPG / PDF** 를 그대로 얹습니다 (PDF 는 첫 페이지 사용)
- 표제란에 **회사 로고**를 넣을 수 있습니다
- 문서 한 건 = JSON 파일 한 개(`.spec.json`) → 복사해서 값만 바꾸면 다음 제품이 됩니다

---

## 1. 실행하는 법

### 방법 A — exe 내려받기 (가장 쉬움, 설치 불필요)

1. GitHub 저장소 → 상단 **Actions** 탭
2. 왼쪽에서 **Build Spec Generator (Windows exe)** 클릭 → 가장 최근 실행 클릭
3. 페이지 맨 아래 **Artifacts** 의 `SpecGenerator-exe` 를 내려받아 압축을 풉니다
4. 나온 `SpecGenerator.exe` 를 더블클릭하면 바로 실행됩니다

> 코드가 바뀔 때마다 exe 가 자동으로 다시 빌드됩니다. 최신본이 필요하면 가장 위의 실행을 받으세요.
> 사내 PC 에 배포할 때는 이 exe 파일 하나만 복사하면 됩니다 (Python 설치 불필요).

### 방법 B — 내 PC 에서 직접 빌드

Python 3.9 이상을 설치한 뒤, 저장소를 내려받아 `spec-generator` 폴더에서:

```bat
build.bat        :: 더블클릭 → dist\SpecGenerator.exe 생성
```

### 방법 C — 소스로 바로 실행 (수정하면서 쓸 때)

```bash
pip install -r requirements.txt
python -m spec_generator                          # 프로그램 실행
python -m spec_generator 파일.spec.json            # 문서를 열면서 실행
```

> **처음 쓰신다면 [사용설명서.md](사용설명서.md) 를 먼저 보세요.**
> 값 입력하는 법, 도번 체계, 리비전 관리 방법이 자세히 적혀 있습니다.
> 프로그램 안에서는 `도움말 → 사용 방법` 으로도 볼 수 있습니다.

## 2. 쓰는 순서

1. **① 기본정보(표제란)**
   제품명, 용도/고객사, 도면번호, DRAWN / CHECKED / APPROVED, **회사 로고**를 입력합니다.
2. **② 문서 구성**
   왼쪽 목록에서 항목을 고르고 오른쪽에서 내용을 채웁니다.
   - **사양표** : `항목 / 항목(영문) / 사양 / 비고` 4열. 엑셀에서 복사 후 **[엑셀에서 붙여넣기]**
   - **첨부 도면** : 모든 항목에 도면을 붙일 수 있습니다 (권선 사양의 보빈 가공도 등).
     폭 `0` = 지면에 맞춰 최대 크기, 가로로 긴 도면은 **회전 `90`** 으로 두 배 가까이 크게
   - **본문** : 한 줄에 한 문장. 들여쓰기 0~3 단계, 머리기호 `(1)` `①` 지원
   - **개정 이력** : 판수 관리표
3. **F5** 미리보기 → **Ctrl+S** 저장 → **Ctrl+E** 고객사 폴더에 PDF 저장

### 값은 이렇게 넣습니다
표는 위아래 두 부분입니다. **위 목록에서 줄을 클릭 → 아래 "▼ 선택한 행 입력" 칸에 타이핑.**
치는 즉시 반영되며 확인 버튼은 없습니다. 엑셀 표가 있으면 복사 후 `엑셀에서 붙여넣기`.

### 도번과 리비전
```
BR - RA - HYU - 0475 - 01          도번은 절대 바꾸지 않는다
│    │    │      │      └ 일련번호   설계가 바뀌면 리비전만 A → B → C
│    │    │      └ 정격전류
│    │    └ 고객코드(영문명에서 자동)
│    └ 제품군
└ Braumm
```
**도번은 직접 만들지 않습니다.** 고객사(영문)와 정격 전류만 넣고 `[도번 자동 생성]` 을 누르면
고객코드와 일련번호를 프로그램이 정해 줍니다. 출력 폴더의 `_도번대장.json` 에 기록되므로
같은 고객이면 늘 같은 코드, 같은 제품군이면 일련번호가 자동으로 올라갑니다.
(`도구 → 도번 대장 보기` 로 검색 가능. 공유 폴더에 두면 팀이 같은 대장을 씁니다)

변경이 생기면 `[▲ 리비전 올리기]` — 개정 이력 표에 자동으로 기록됩니다.

### 한 번 입력한 값 다시 쓰기
표나 본문에 `{고객사}` `{제품명}` `{도번}` `{리비전}` `{정격전류}` 처럼 적어 두면
PDF 를 만들 때 ① 기본정보 값으로 자동으로 바뀝니다.
표준 템플릿의 기본 사양 표에는 이미 들어가 있어서, 기본정보만 채우면 저절로 채워집니다.

### 고객 승인 사양서
`Ctrl+E` 한 번에 **생산 사양서 + 고객 승인 사양서** 두 개가 만들어집니다.
항목의 **공개 범위 기본값은 `생산용만`** 이라, 표시하지 않은 항목은 고객 문서에 실리지 않습니다.
`출력 → 고객에게 나가는 내용 확인` 으로 점검하고, `F6` 으로 미리볼 수 있습니다.

### PDF 저장 위치
`출력 → 출력 폴더 설정` 에서 폴더를 한 번 정해 두면, `Ctrl+E` 를 누를 때마다
`{출력폴더}/{고객사}/BR-RA-HYU-0475-01_RevB_20260901.pdf` 로 알아서 저장됩니다.

문서를 저장(`Ctrl+S`)하면 `.spec.json` 이 생기고, 이후 추가하는 도면은 그 옆 `figures/`
폴더로 자동 복사됩니다. **폴더째** 주고받으면 됩니다.

### 로고 넣기
`① 기본정보 → 회사 로고 → 찾아보기` 에서 PNG/JPG 를 고르면 표제란 하단에 들어갑니다.
비워 두면 문서 파일과 같은 폴더의 `logo.png` 를 자동으로 씁니다.
회사 공통으로 쓰려면 `assets/logo.png` 에 넣어 두세요 (exe 에도 함께 포함됩니다).

## 3. 표준 템플릿 (리액터)

`파일 → 표준 템플릿으로 새로 만들기` 를 누르면 아래 구성이 항목명까지 채워진 채로 시작합니다.
사양 값만 채워 넣고 도면을 붙이면 됩니다.

| # | 항목 | 들어가는 것 |
|---|------|------------|
| 1 | 적용 범위 | 정형 문구 |
| 2 | 기본 사양 | 고객사 · 정격전류 · 인덕턴스 · 정격전압 · 상수 · 절연등급 · 냉각방식 … |
| 3 | 외형도 | 도면 첨부 |
| 4 | 권선 사양 | **권선 턴수** · 전선 재질/규격 · 층수 · 인출선 · 단자 형태 |
| 5 | 요크 코어 | 재질 · 두께 · 폭 · 길이 · 적층높이 · 매수 + **도면** |
| 6 | 다리 코어 | 위와 동일 + 다리 개수 + **도면** |
| 7 | 갭 | **갭 두께 · 갭 개수** · 총 갭 길이 · 갭 위치 + **도면** |
| 8 | SUS 부품 | 재질 · 두께 · 폭 · 길이 · 수량 · 표면처리 + **도면** |
| 9 | 보빈 | 품번 · 재질 · 내경 · 높이 · 두께 · 수량 |
| 10 | 체결 부품 | **볼트 규격** · 재질/등급 · 수량 · 너트 · 와셔 · 체결토크 |
| 11 | 판금물 | 재질 · 두께 · 전개치수 · 완성치수 · 표면처리 + **도면** |
| 12 | 조립 및 작업 지시 | 정형 문구 |
| 13 | 시험 · 검사 | 전수검사 / 형식시험 항목 |
| 14 | 포장 · 표시 · 취급 | 정형 문구 |
| 15 | 개정 이력 | 판수 관리표 |

항목은 얼마든지 추가·삭제·순서 변경할 수 있고, 번호는 자동으로 다시 매겨집니다.
자주 쓰는 구성이 생기면 `파일 → 현재 문서를 템플릿으로 저장` 으로 템플릿을 늘려 가세요
(사용자 템플릿은 `~/.spec_generator_templates` 에 저장됩니다).

`samples/예제_리액터_475A.spec.json` 은 값을 채워 넣은 예제입니다. 열어서 구조를 보세요.

## 4. 명령줄

```bash
python -m spec_generator build samples/예제_리액터_475A.spec.json -o 출력.pdf
python -m spec_generator templates          # 템플릿 목록
python -m spec_generator selftest           # 호환성 자체 점검
```

### 예전 문서도 업데이트를 따라갑니다

프로그램에 항목이 추가되면, 이미 저장해 둔 문서도
`도구 → 최신 템플릿의 추가 항목 가져오기` 로 그 항목을 가져올 수 있습니다.
**더하기만 하고** 이미 적어 둔 값은 덮어쓰지 않으며, 무엇이 들어올지 먼저 보여 주고 고르게 합니다.

### 예전에 저장한 문서는 계속 열립니다

프로그램을 계속 고쳐도 이미 만든 `.spec.json` 이 열리지 않는 일이 없도록:

- 파일에 `schema` / `app_version` 을 기록하고, 구조가 바뀌면 열 때 자동 변환합니다
- 모르는 필드는 무시하므로, 새 파일을 옛 프로그램으로 열어도 죽지 않습니다
- `tests/fixtures` 에 **각 버전에서 실제로 저장한 파일**을 얼려 두고,
  `selftest` 가 매번 "여전히 열리고 PDF 가 나오는지" 검사합니다.
  CI 에서 이 검사가 실패하면 exe 빌드가 중단됩니다.

필드 이름을 바꿔야 할 때는 반드시 `model.py` 의 `_LEGACY_KEYS` 에 매핑을 남기고,
구조를 바꿀 때는 `_MIGRATIONS` 에 변환 함수를 추가한 뒤 `SCHEMA_VERSION` 을 올립니다.
템플릿에 항목을 추가할 때는 `key` 를 꼭 붙여야 예전 문서가 그것을 알아보고 가져갈 수 있습니다.

## 5. 보안

- **바깥으로 나가는 통신이 없습니다.** 네트워크 코드가 아예 없고 `selftest` 가 매번 검사합니다.
  자동 업데이트·사용기록 수집·외부 조회 없음. `eval`/`exec`/`pickle`/셸 실행 없음.
- 건드리는 파일은 설정(`~/.spec_generator.json`), 템플릿, 출력 폴더, 임시 폴더뿐입니다.
- **도장·사인 이미지는 서명과 같습니다.** `assets/stamps/` 는 `.gitignore` 로 막아 두었으니
  저장소에 올리지 말고, 공유 폴더에 둘 때 접근 권한을 확인하세요.
- **주의** : 모르는 사람이 준 `.spec.json` 은 열지 마세요(도면 경로가 들어 있습니다).
  고객 PDF 를 다루므로 `pymupdf` 는 가끔 최신으로 올려 주세요. exe 에는 서명이 없습니다.
- **저장소를 Private 로 두세요.** 실제 사양서와 고객 도면은 저장소가 아니라 사내 폴더에 둡니다.
  자세한 내용은 [사용설명서 10장](사용설명서.md) 참고.

## 7. 구조 · 손보는 곳

```
spec-generator/
├─ run_app.py / build.bat / SpecGenerator.spec     실행·빌드
├─ samples/예제_리액터_475A.spec.json               값을 채운 예제
├─ assets/fonts/ , assets/logo.png                 (선택) 번들 폰트·로고
└─ spec_generator/
   ├─ model.py           데이터 모델 + JSON 저장/불러오기
   ├─ fonts.py           한글 폰트 탐색·등록
   ├─ importers.py       엑셀 붙여넣기 파싱, 도면 PDF→이미지, 로고 탐색
   ├─ templates/         표준 템플릿 (reactor.spec.json)
   ├─ render/
   │  ├─ frame.py        도면 양식(외곽선·표제란·로고) — 치수는 전부 mm 상수
   │  ├─ flow.py         항목 → 본문·표·도면 변환
   │  └─ build.py        PDF 조판 (페이지 총수 자동 계산)
   └─ gui/               화면
```

- **양식 칸 위치·크기** → `render/frame.py` 위쪽 mm 상수
- **표 열 너비·글자 크기** → `render/flow.py` 의 `SPEC_WIDTHS`, `make_styles()`
- **템플릿 항목** → `spec_generator/templates/reactor.spec.json` (또는 프로그램에서 만들어 저장)
