# Braumm 생산 사양서 생성기 — 사용설명서

## 0. 프로그램 실행

`SpecGenerator.exe` 를 더블클릭합니다. 설치 과정은 없습니다.
(내려받는 방법은 README 의 "실행하는 법" 참고)

처음 한 번만 해 두면 좋은 설정:

- **출력 → 출력 폴더 설정** — 사양서를 모아 둘 폴더를 지정합니다.
  예) `D:\사양서` 로 정하면, 이후 저장할 때 `D:\사양서\현대일렉트릭\...` 처럼
  고객사 폴더가 자동으로 만들어집니다.
- **① 기본정보 → 회사 로고** — 로고 파일을 한 번 지정해 두면 **표지와 표제란**에 들어갑니다.

## 1. 한 건 만드는 전체 흐름

```
파일 → 표준 템플릿으로 새로 만들기
   ↓
① 기본정보 : 고객사 · 정격전류 입력 → [도번 자동 생성]
   ↓
② 문서 구성 : 항목별로 값 입력 + 도면 첨부
   ↓
F5 (미리보기) 로 확인
   ↓
Ctrl+S (저장)  →  Ctrl+E (고객사 폴더에 PDF 저장)
```

---

## 2. ★ 값을 넣는 방법 — 가장 헷갈리는 부분

표(사양표·개정 이력)는 **위아래 두 부분**으로 되어 있습니다.

```
┌─────────────────────────────────────────┐
│  항목        항목(영문)    사양    비고   │  ← 위: 전체 목록 (읽는 곳)
│  고객사      Customer                    │
│▶ 정격 전류   Rated current  475 Arms     │  ← 클릭해서 고를 행
│  인덕턴스    Inductance                  │
├─────────────────────────────────────────┤
│ ▼ 선택한 행 입력                          │  ← 아래: 값을 적는 곳
│   항목 [정격 전류      ]                  │
│   사양 [475 Arms       ]                  │
│   비고 [Arms           ]                  │
└─────────────────────────────────────────┘
```

1. **위 목록에서 고칠 줄을 한 번 클릭**합니다.
2. **아래 "▼ 선택한 행 입력" 칸에 타이핑**합니다.
3. 치는 즉시 위 목록에도 반영됩니다. **따로 확인 버튼은 없습니다.**

| 하고 싶은 것 | 방법 |
|---|---|
| 줄 새로 만들기 | `＋ 행 추가` |
| 줄 순서 바꾸기 | `▲` `▼` |
| 줄 지우기 | `행 삭제` |
| 한 칸 안에서 줄바꿈 | 아래 입력칸에서 그냥 **Enter** |
| 목록에서 바로 고치기 | 칸을 **더블클릭** |
| 엑셀 표 그대로 넣기 | 엑셀에서 범위 복사 → `엑셀에서 붙여넣기` |

> **엑셀 붙여넣기 열 순서**
> 사양표 : `항목` `항목(영문)` `사양` `비고`
> 개정 이력 : `리비전` `작성자` `발행일` `변경 내용` `변경 내용(영문)`
> 영문 칸을 안 쓰면 빈 칸으로 두면 됩니다.

## 3. 도면 붙이기

**모든 항목**에 도면을 붙일 수 있습니다. 항목을 고르면 내용 영역에 **[첨부 도면]** 탭이 있고,
탭 이름에 `첨부 도면 (2)` 처럼 붙어 있는 개수가 표시됩니다.

1. `＋ 도면 파일 추가...` → PNG / JPG / **PDF** 선택 (PDF 는 첫 페이지가 들어갑니다)
2. 아래 입력칸에서 크기를 정합니다.

| 칸 | 넣는 값 |
|---|---|
| **폭(mm)** | **`0` = 지면에 맞춰 최대 크기 (권장)** · 숫자를 넣으면 그 폭으로 고정 (최대 170) |
| **회전** | `0` 또는 `90`. **가로로 긴 도면은 `90`** 을 넣으면 세로 지면에 두 배 가까이 크게 들어갑니다 |
| 정렬 | LEFT / CENTER / RIGHT |
| 도면 설명 | 그림 아래에 캡션으로 붙습니다 |

> **도면이 작게 나온다면** 폭을 `0` 으로 두고, 그래도 작으면 **회전을 `90`** 으로 해 보세요.
> 가로로 긴 도면은 세로 A4 에서 폭에 막혀 위아래가 남는데, 90도 돌리면 지면을 꽉 채웁니다.
> 그 항목의 `이 항목부터 새 페이지` 를 켜면 도면 한 장이 온전히 한 페이지를 씁니다.

한 항목이 **표와 도면을 함께** 가질 수 있습니다.
- `5. 요크 코어` → [사양표] 탭에 치수, [첨부 도면] 탭에 코어 도면
- `4. 권선 사양` → [사양표] 탭에 턴수·전선, [첨부 도면] 탭에 **보빈 가공도**·결선도

> 문서를 한 번 저장(`Ctrl+S`)해 두면, 이후 추가하는 도면은 문서 옆
> `figures` 폴더로 **자동 복사**됩니다. 폴더째 주고받으면 도면이 깨지지 않습니다.

## 4. 도면번호(도번) 체계

```
BR - RA - HYU - 0475 - 01
│    │    │      │      └ 일련번호 : 같은 고객·같은 정격에서 사양이 다른 제품 구분
│    │    │      └ 정격전류 4자리 : 475A → 0475
│    │    └ 고객코드 3자리 : 영문 고객명에서 자동 (Hyundai Electric → HYU)
│    └ 제품군 2자리
└ Braumm
```

**제품군 코드**

| 코드 | 제품 | 코드 | 제품 |
|---|---|---|---|
| RA | AC 리액터 | CH | 초크 코일 |
| RD | DC 리액터 | TR | 변압기 |
| RL | 라인 리액터 | CT | 계기용 변류기 |
| RZ | 영상 리액터 | ET | 기타 |

### 도번은 직접 만들지 않습니다 — 자동 발급

① 기본정보 탭에 **고객사(한글/영문)** 와 **정격 전류** 만 넣고
**[도번 자동 생성]** 을 누르면 끝입니다. 고객코드도 일련번호도 프로그램이 정합니다.

- **고객코드** : 영문명에서 자동. 첫 낱말이 3글자 이상이면 앞 3글자, 짧으면 다음 낱말의 첫 글자.
  `Hyundai Electric → HYU`, `LS Electric → LSE`, `LG Energy Solution → LGE`
  이미 발급한 적 있는 고객이면 **그때 준 코드를 그대로** 씁니다.
  다른 고객인데 코드가 겹치면(`Hyundai Electric` / `Hyundai Heavy`) 자동으로 피해 갑니다 → `HYU` / `HYN`
- **일련번호** : 같은 (제품군 · 고객 · 정격) 안에서 다음 번호로 자동 증가.
  `BR-RA-HYU-0475-01` 다음은 `-02`

### 도번 대장

출력 폴더에 `_도번대장.json` 이 자동으로 만들어져, 발급한 번호와 고객코드가 전부 기록됩니다.
**도구 → 도번 대장 보기** 로 "이 고객한테 예전에 뭘 만들었더라" 를 검색할 수 있습니다.

> 출력 폴더를 **공유 폴더(네트워크 드라이브)** 로 잡아 두면 팀 전체가 같은 대장을 쓰게 되어
> 번호가 겹치지 않습니다. 이게 가장 권장하는 방식입니다.

## 3-1. 표지

PDF 첫 장에 표지가 붙습니다. **① 기본정보 → 표지** 에서 끄고 켤 수 있습니다.

표지에 들어가는 것 (전부 기본정보 값에서 자동으로 채워집니다):

- 회사 **로고** 와 회사명
- 큰 제목(문서종류) + 영문 부제 — 부제는 기본정보에서 바꿀 수 있습니다
- 제품명 / 고객사 / 용도 / 도면번호 / 리비전 / 발행일
- 작성 · 검토 · 승인란 (**도장 / 사인 이미지**를 찍을 수 있습니다 — 아래 참고)
- 기밀 문구

### 도장 · 사인 넣기

**① 기본정보 → 작성 · 검토 · 승인** 에서 사람별로 이름 · 일자 · 도장 파일을 넣습니다.

| 방법 | 하는 법 |
|---|---|
| **한 번만 넣고 계속 쓰기 (권장)** | 프로그램 폴더의 `assets\stamps\` 에 **`이름.png`** 로 저장 (예: `홍길동.png`).<br>도장 칸은 비워 둡니다. 그 이름을 쓸 때마다 자동으로 찍힙니다 |
| 문서마다 다르게 | 도장 칸의 `찾아보기` 로 파일을 직접 고릅니다 |
| 문서 폴더에 두기 | 문서 옆 `stamps\이름.png` 도 자동으로 찾습니다 |

- **PNG 배경 투명 권장** (JPG 도 되지만 흰 사각형이 같이 찍힙니다)
- 도장은 정사각형(300×300px 정도), 사인은 가로로 긴 이미지도 됩니다 — 알아서 맞춰 들어갑니다
- 도장을 넣으면 이름은 그 아래 작게, 안 넣으면 이름이 크게 나옵니다
- 표지뿐 아니라 **각 장 표제란의 APPROVED 칸**에도 승인 도장이 찍힙니다
- 파일이 없거나 깨져 있어도 문서 생성은 그대로 됩니다 (도장만 안 찍힘)

> ★ **도장·사인 이미지는 서명과 같은 효력을 가질 수 있습니다.**
> 저장소(git)에 올라가지 않도록 `.gitignore` 에 넣어 두었습니다.
> 공유 폴더에 둘 때는 접근 권한을 꼭 확인하세요.

> 표지에는 도면 양식(외곽선·표제란)이 들어가지 않고, **쪽 번호에서도 빠집니다.**
> 즉 내용 첫 장이 `PAGE 1` 입니다.

## 4-1. 한 번 입력한 값 다시 쓰기 (자동 입력 항목)

고객사·품명 같은 값을 여기저기 다시 적을 필요가 없습니다.
표나 본문에 **중괄호 항목**을 적어 두면 PDF 를 만들 때 ① 기본정보 값으로 바뀝니다.

| 적는 것 | 바뀌는 값 |
|---|---|
| `{고객사}` | 기본정보의 고객사(한글) |
| `{고객사영문}` | 고객사(영문) |
| `{제품명}` | 제품명 |
| `{용도}` | 용도 / 고객 모델 |
| `{도번}` | `BR-RA-HYU-0475-01` |
| `{리비전}` | `B` |
| `{발행일}` | 리비전 발행일 |
| `{정격전류}` | 기본정보의 정격 전류 |
| `{제품군}` | `AC 리액터 (AC Reactor)` |
| `{회사명}` | Braumm |
| `{오늘}` | PDF 를 만든 날짜 |

표준 템플릿의 **기본 사양** 표에는 이미 들어가 있습니다.
`고객사 → {고객사}`, `품명 → {제품명}`, `모델/형번 → {도번}`, `정격 전류 → {정격전류}`
따라서 ① 기본정보만 채우면 이 네 줄은 저절로 채워집니다.

- 목록에서는 `{고객사}` 그대로 보이고, **PDF 에서만** 실제 값으로 바뀝니다 (F5 로 확인).
- 오타로 없는 항목을 적으면 (`{고객명}` 등) 바뀌지 않고 그대로 보입니다 — 일부러 그렇게 했습니다.
- 목록은 **도구 → 쓸 수 있는 자동 입력 항목** 에서도 볼 수 있습니다.

## 5. 리비전 관리 — 이렇게 하시면 안전합니다

### 다섯 가지 원칙

1. **도번은 절대 바꾸지 않는다.**
   사양이 조금 바뀌었다고 도번을 바꾸면, 현장·구매·재고가 전부 어긋납니다.
   *제품 자체가 달라졌을 때만* 새 도번(일련번호 `-02`)을 땁니다.

2. **바뀌면 리비전을 올린다. A → B → C**
   `[▲ 리비전 올리기]` 버튼 하나면 됩니다. 변경 내용을 적으면
   개정 이력 표에 `리비전 / 작성자 / 발행일 / 변경 내용` 이 자동으로 기록됩니다.

3. **한 번이라도 밖으로 나갔으면 무조건 올린다.**
   "오타만 고쳤으니까" 하고 같은 리비전으로 다시 뿌리는 것이 가장 위험합니다.
   현장에 같은 이름의 다른 문서가 두 개 돌아다니게 됩니다.
   아직 아무에게도 안 준 초안이면 올리지 않아도 됩니다.

4. **파일 이름에 리비전을 넣는다.**
   `BR-RA-HYU-0475-01_RevB_20260901.pdf`
   현장에서 파일만 봐도 최신본인지 알 수 있고, 구본과 섞이지 않습니다.
   (`Ctrl+E` 로 저장하면 이 이름이 자동으로 붙습니다)

5. **구본은 지우지 말고 옮긴다.**
   고객사 폴더 안에 `_구본` 폴더를 만들어 옮겨 두세요.
   "그때 어떤 사양으로 만들었나"를 되짚어야 할 일이 반드시 생깁니다.

### 실제 운영 예

```
D:\사양서\현대일렉트릭\
    BR-RA-HYU-0475-01_RevC_20261120.pdf     ← 현재 유효본
    BR-RA-HYU-0475-01.spec.json             ← 편집용 원본 (이것만 고친다)
    figures\                                 ← 도면들
    _구본\
        BR-RA-HYU-0475-01_RevA_20260901.pdf
        BR-RA-HYU-0475-01_RevB_20261005.pdf
```

- `.spec.json` 은 **하나만** 두고 계속 고칩니다. 리비전마다 복사하지 않습니다.
  (변경 내역은 개정 이력 표에 다 남습니다)
- PDF 는 리비전마다 새 파일이 생깁니다. 이것이 "그 시점의 사진" 역할을 합니다.
- 명판에 찍는 리비전 = 문서 우측 하단 `REV.` 칸의 글자.

### 언제 새 도번을 따야 하나

| 상황 | 조치 |
|---|---|
| 갭 두께 0.5 → 0.8mm 변경 | **리비전 up** (B) |
| 볼트 M8 → M10 변경 | **리비전 up** |
| 오타 수정, 문구 정리 | **리비전 up** (이미 배포했다면) |
| 정격전류 475A → 600A | **새 도번** (`-0600-01`) |
| 같은 정격인데 외형이 완전히 다른 별개 제품 | **새 도번** (`-0475-02`) |
| 고객사가 다름 | **새 도번** (고객코드가 다름) |

## 6. 저장 · 불러오기 · 다음 제품 만들기

| 동작 | 단축키 | 결과 |
|---|---|---|
| 저장 | `Ctrl+S` | `.spec.json` — **이 파일이 원본입니다** |
| 열기 | `Ctrl+O` | 저장해 둔 `.spec.json` 불러오기 |
| 최근 문서 | 파일 → 최근에 연 문서 | 최근 12건에서 바로 선택 |
| PDF 미리보기 | `F5` | 임시 파일로 열어 봄 |
| 고객사 폴더에 PDF 저장 | `Ctrl+E` | `{출력폴더}\{고객사}\{도번}_Rev{리비전}_{날짜}.pdf` |

**다음 제품을 만드는 가장 빠른 방법**
비슷한 제품의 `.spec.json` 을 열고 → `파일 → 다른 이름으로 저장` →
고객사/정격전류를 바꾸고 `[도번 자동 생성]` → 값만 수정.

**파일 이름 규칙 바꾸기** : 출력 → 파일 이름 규칙
쓸 수 있는 항목 : `{도번}` `{리비전}` `{날짜}` `{발행일}` `{고객사}` `{제품명}`

## 7. 항목 늘리고 줄이기

왼쪽 목록 아래에서 종류를 고르고 `추가` 를 누릅니다.

| 종류 | 쓰임 |
|---|---|
| 본문 항목 | 글로 쓰는 지시사항 (조립 순서, 검사 항목 등) |
| 사양표 | 항목 / 사양 / 비고 표 — 가장 많이 씁니다 |
| 도면/그림 | 도면만 크게 넣을 때 (외형도 등) |
| 판수관리표 | 개정 이력 |

- `복제` : 비슷한 항목을 만들 때 (예: 요크 코어 → 복제 → 다리 코어)
- `▲` `▼` : 순서 변경
- **번호(1. 2. 3. …)와 PAGE n/N 은 항상 자동으로 다시 매겨집니다.**
- `이 항목부터 새 페이지` 를 켜면 그 항목이 새 장에서 시작합니다.

우리 회사 표준 구성이 정해지면
`파일 → 현재 문서를 템플릿으로 저장` 해 두고 다음부터 그걸로 시작하세요.

## 8. 프로그램이 업데이트되면, 예전 문서도 따라 올라갑니다

프로그램에 항목이 추가되면 (예: 표준 템플릿에 "냉각 사양" 항목이 새로 생김),
**이미 저장해 둔 예전 문서도 그 항목을 가져올 수 있습니다.**

### 하는 법

1. 예전 문서를 엽니다 (`Ctrl+O`)
2. **도구 → 최신 템플릿의 추가 항목 가져오기**
3. 새로 생긴 것들이 목록으로 뜹니다. 가져올 것만 켜고 **[선택한 것 가져오기]**
4. 내용을 확인하고 저장 (`Ctrl+S`)

### 가져오는 것

| 종류 | 내용 |
|---|---|
| 새 항목 | 템플릿에 새로 생긴 장(章). 템플릿과 같은 위치에 들어갑니다 |
| 표에 줄 추가 | 사양표에 새로 생긴 항목 줄 (예: 기본 사양의 "총 중량") |
| 본문 문구 추가 | 지시사항에 새로 생긴 문장 |
| 빈 칸 채우기 | 비어 있는 칸에 템플릿 기본값(자동 입력 항목 등)을 넣어 줍니다 |

### 안전 장치 — 더하기만 합니다

- **이미 적어 둔 값은 절대 덮어쓰지 않습니다.** 채워져 있는 칸은 건드리지 않습니다.
- **아무것도 지우지 않습니다.** 직접 추가한 항목·줄은 그대로 남습니다.
- **미리 보여 주고 고르게 합니다.** 원하지 않는 것은 꺼 두면 됩니다.
- **두 번 눌러도 중복으로 들어가지 않습니다.**

> 항목을 알아보는 기준은 **제목**(과 내부 고정 이름)입니다.
> 항목 제목을 크게 바꿔 두었다면 "이미 있는 것"으로 못 알아보고 새로 추가하자고 할 수 있습니다.
> 그럴 때는 그 줄만 꺼 두세요.

## 9. 지금 만든 문서, 나중에도 계속 열립니다

프로그램을 계속 고쳐 나가도 **예전에 저장한 `.spec.json` 은 그대로 열리고 이어서 수정할 수 있습니다.**

1. **파일에 버전이 찍힙니다** (`schema`, `app_version`).
2. **구조가 바뀌면 열 때 자동으로 변환합니다.**
   실제로 초기 버전(일본어 병기)으로 저장한 파일도 지금 그대로 열립니다.
3. **모르는 항목은 무시합니다.** 새 버전에서 만든 파일을 옛 프로그램으로 열어도 죽지 않습니다.
4. **얼려 둔 문서로 매번 검증합니다.**
   `tests/fixtures` 에 각 버전에서 저장한 실제 파일이 들어 있고, 코드를 고칠 때마다
   "이 파일들이 여전히 열리고, PDF 가 나오고, 새 항목을 가져올 수 있는지" 를 검사합니다.
   통과하지 못하면 exe 빌드 자체가 실패합니다.

```bash
python -m spec_generator selftest      # 직접 확인해 보고 싶을 때
```

> **당부** : `.spec.json` 과 그 옆의 `figures` 폴더는 **함께** 보관해 주세요.
> 도면 경로가 상대경로라 폴더째 옮기면 안전하지만 파일만 옮기면 도면이 빠집니다.

## 10. 보안 — 무엇이 안전하고 무엇을 조심해야 하나

### 안전한 부분 (자동 검사 항목)

- **바깥으로 나가는 통신이 전혀 없습니다.** 네트워크 관련 코드 자체가 들어 있지 않고,
  `selftest` 가 매번 이를 검사합니다. 입력한 사양·도면·고객사 정보가 어디로도 전송되지 않습니다.
- 자동 업데이트, 사용 기록 수집, 외부 서버 조회 같은 기능이 없습니다.
- `eval` / `exec` / `pickle` / 셸 실행 같은 위험한 호출을 쓰지 않습니다.
- 비밀번호·API 키를 저장하지 않습니다.

### 프로그램이 건드리는 파일

| 위치 | 내용 |
|---|---|
| `%USERPROFILE%\.spec_generator.json` | 출력 폴더, 최근 문서 목록, 폰트 설정 |
| `%USERPROFILE%\.spec_generator_templates\` | 직접 저장한 템플릿 |
| 출력 폴더 | PDF, `.spec.json`, `figures`, `_도번대장.json` |
| 임시 폴더 | 미리보기 PDF, 도면 PDF 를 그림으로 바꾼 캐시 |

### 조심해야 할 것

1. **모르는 사람이 준 `.spec.json` 은 열지 마세요.**
   문서 파일 안에는 도면 파일 경로가 들어 있습니다. 악의적으로 만든 파일이라면
   PC 안의 엉뚱한 파일 경로를 적어 두어 그 내용이 PDF 에 실려 나갈 수 있습니다.
   **사내에서 만든 파일만** 여세요.
2. **고객이 보낸 PDF 도면을 붙일 때**
   PDF 를 그림으로 바꾸는 데 외부 라이브러리(PyMuPDF)를 씁니다. 이런 파일 형식 처리기는
   가끔 취약점이 나오므로, `requirements.txt` 의 라이브러리를 **가끔 최신으로 올려** 주세요.
3. **exe 에 서명이 없습니다.** 처음 실행할 때 Windows SmartScreen 경고가 뜹니다.
   반드시 **본인 저장소의 Actions 에서 받은 파일**인지 확인하고 실행하세요.
4. **도번 대장을 공유 폴더에 둘 때** 두 사람이 정확히 같은 순간에 도번을 발급하면
   한쪽 기록이 덮일 수 있습니다(파일 잠금이 없습니다). 실제로는 거의 없는 일이지만,
   대장에 이상이 보이면 `도구 → 도번 대장 보기` 로 확인하세요.
