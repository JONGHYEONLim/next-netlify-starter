# Braumm 생산 사양서 생성기 — 사용설명서

## 0. 프로그램 실행

`SpecGenerator.exe` 를 더블클릭합니다. 설치 과정은 없습니다.
(내려받는 방법은 README 의 "실행하는 법" 참고)

처음 한 번만 해 두면 좋은 설정:

- **출력 → 출력 폴더 설정** — 사양서를 모아 둘 폴더를 지정합니다.
  예) `D:\사양서` 로 정하면, 이후 저장할 때 `D:\사양서\현대일렉트릭\...` 처럼
  고객사 폴더가 자동으로 만들어집니다.
- **① 기본정보 → 회사 로고** — 로고 파일을 한 번 지정해 두면 표제란에 들어갑니다.

---

## 1. 한 건 만드는 전체 흐름

```
파일 → 표준 템플릿으로 새로 만들기
   ↓
① 기본정보 : 고객사 · 정격전류 입력 → [도번 자동 생성]
   ↓
② 문서 구성 : 항목별로 값 입력 + 도면 첨부
   ↓
F5 (미리보기) 로 확인
   ↓
Ctrl+S (저장)  →  Ctrl+E (고객사 폴더에 PDF 저장)
```

---

## 2. ★ 값을 넣는 방법 — 가장 헷갈리는 부분

표(사양표·개정 이력)는 **위아래 두 부분**으로 되어 있습니다.

```
┌─────────────────────────────────────────┐
│  항목        항목(영문)    사양    비고   │  ← 위: 전체 목록 (읽는 곳)
│  고객사      Customer                    │
│▶ 정격 전류   Rated current  475 Arms     │  ← 클릭해서 고를 행
│  인덕턴스    Inductance                  │
├─────────────────────────────────────────┤
│ ▼ 선택한 행 입력                          │  ← 아래: 값을 적는 곳
│   항목 [정격 전류      ]                  │
│   사양 [475 Arms       ]                  │
│   비고 [Arms           ]                  │
└─────────────────────────────────────────┘
```

1. **위 목록에서 고칠 줄을 한 번 클릭**합니다.
2. **아래 "▼ 선택한 행 입력" 칸에 타이핑**합니다.
3. 치는 즉시 위 목록에도 반영됩니다. **따로 확인 버튼은 없습니다.**

| 하고 싶은 것 | 방법 |
|---|---|
| 줄 새로 만들기 | `＋ 행 추가` |
| 줄 순서 바꾸기 | `▲` `▼` |
| 줄 지우기 | `행 삭제` |
| 한 칸 안에서 줄바꿈 | 아래 입력칸에서 그냥 **Enter** |
| 목록에서 바로 고치기 | 칸을 **더블클릭** |
| 엑셀 표 그대로 넣기 | 엑셀에서 범위 복사 → `엑셀에서 붙여넣기` |

> **엑셀 붙여넣기 열 순서**
> 사양표 : `항목` `항목(영문)` `사양` `비고`
> 개정 이력 : `리비전` `작성자` `발행일` `변경 내용` `변경 내용(영문)`
> 영문 칸을 안 쓰면 빈 칸으로 두면 됩니다.

## 3. 도면 붙이기

항목을 고르면 내용 영역에 **[첨부 도면]** 탭이 있습니다.

1. `＋ 도면 파일 추가...` → PNG / JPG / **PDF** 선택 (PDF 는 첫 페이지가 들어갑니다)
2. 아래 입력칸에서 **폭(mm)** 을 조정합니다. 본문 최대 폭은 **170mm**.
   - 전체 폭으로 크게 → `165`
   - 반 폭 정도 → `85`
3. **도면 설명** 을 적으면 그림 아래에 캡션으로 붙습니다.

한 항목이 **표와 도면을 함께** 가질 수 있습니다.
예) `5. 요크 코어` → [사양표] 탭에 치수, [첨부 도면] 탭에 도면.

> 문서를 한 번 저장(`Ctrl+S`)해 두면, 이후 추가하는 도면은 문서 옆
> `figures` 폴더로 **자동 복사**됩니다. 폴더째 주고받으면 도면이 깨지지 않습니다.

## 4. 도면번호(도번) 체계

```
BR - RA - HYU - 0475 - 01
│    │    │      │      └ 일련번호 : 같은 고객·같은 정격에서 사양이 다른 제품 구분
│    │    │      └ 정격전류 4자리 : 475A → 0475
│    │    └ 고객코드 3자리 : 영문 고객명에서 자동 (Hyundai Electric → HYU)
│    └ 제품군 2자리
└ Braumm
```

**제품군 코드**

| 코드 | 제품 | 코드 | 제품 |
|---|---|---|---|
| RA | AC 리액터 | CH | 초크 코일 |
| RD | DC 리액터 | TR | 변압기 |
| RL | 라인 리액터 | CT | 계기용 변류기 |
| RZ | 영상 리액터 | ET | 기타 |

**만드는 법** : ① 기본정보 탭에서 `고객사(영문)`, `제품군`, `정격 전류`, `일련번호` 를
넣고 **[도번 자동 생성]** 을 누르면 됩니다. 직접 고쳐 써도 됩니다.

**고객코드 규칙** : 영문명 첫 낱말이 3글자 이상이면 앞 3글자, 짧으면 다음 낱말의 첫 글자로 채웁니다.
`Hyundai Electric → HYU`, `LS Electric → LSE`, `LG Energy Solution → LGE`, `ABB → ABB`

## 5. 리비전 관리 — 이렇게 하시면 안전합니다

### 다섯 가지 원칙

1. **도번은 절대 바꾸지 않는다.**
   사양이 조금 바뀌었다고 도번을 바꾸면, 현장·구매·재고가 전부 어긋납니다.
   *제품 자체가 달라졌을 때만* 새 도번(일련번호 `-02`)을 땁니다.

2. **바뀌면 리비전을 올린다. A → B → C**
   `[▲ 리비전 올리기]` 버튼 하나면 됩니다. 변경 내용을 적으면
   개정 이력 표에 `리비전 / 작성자 / 발행일 / 변경 내용` 이 자동으로 기록됩니다.

3. **한 번이라도 밖으로 나갔으면 무조건 올린다.**
   "오타만 고쳤으니까" 하고 같은 리비전으로 다시 뿌리는 것이 가장 위험합니다.
   현장에 같은 이름의 다른 문서가 두 개 돌아다니게 됩니다.
   아직 아무에게도 안 준 초안이면 올리지 않아도 됩니다.

4. **파일 이름에 리비전을 넣는다.**
   `BR-RA-HYU-0475-01_RevB_20260901.pdf`
   현장에서 파일만 봐도 최신본인지 알 수 있고, 구본과 섞이지 않습니다.
   (`Ctrl+E` 로 저장하면 이 이름이 자동으로 붙습니다)

5. **구본은 지우지 말고 옮긴다.**
   고객사 폴더 안에 `_구본` 폴더를 만들어 옮겨 두세요.
   "그때 어떤 사양으로 만들었나"를 되짚어야 할 일이 반드시 생깁니다.

### 실제 운영 예

```
D:\사양서\현대일렉트릭\
    BR-RA-HYU-0475-01_RevC_20261120.pdf     ← 현재 유효본
    BR-RA-HYU-0475-01.spec.json             ← 편집용 원본 (이것만 고친다)
    figures\                                 ← 도면들
    _구본\
        BR-RA-HYU-0475-01_RevA_20260901.pdf
        BR-RA-HYU-0475-01_RevB_20261005.pdf
```

- `.spec.json` 은 **하나만** 두고 계속 고칩니다. 리비전마다 복사하지 않습니다.
  (변경 내역은 개정 이력 표에 다 남습니다)
- PDF 는 리비전마다 새 파일이 생깁니다. 이것이 "그 시점의 사진" 역할을 합니다.
- 명판에 찍는 리비전 = 문서 우측 하단 `REV.` 칸의 글자.

### 언제 새 도번을 따야 하나

| 상황 | 조치 |
|---|---|
| 갭 두께 0.5 → 0.8mm 변경 | **리비전 up** (B) |
| 볼트 M8 → M10 변경 | **리비전 up** |
| 오타 수정, 문구 정리 | **리비전 up** (이미 배포했다면) |
| 정격전류 475A → 600A | **새 도번** (`-0600-01`) |
| 같은 정격인데 외형이 완전히 다른 별개 제품 | **새 도번** (`-0475-02`) |
| 고객사가 다름 | **새 도번** (고객코드가 다름) |

## 6. 저장 · 불러오기 · 다음 제품 만들기

| 동작 | 단축키 | 결과 |
|---|---|---|
| 저장 | `Ctrl+S` | `.spec.json` — **이 파일이 원본입니다** |
| 열기 | `Ctrl+O` | 저장해 둔 `.spec.json` 불러오기 |
| 최근 문서 | 파일 → 최근에 연 문서 | 최근 12건에서 바로 선택 |
| PDF 미리보기 | `F5` | 임시 파일로 열어 봄 |
| 고객사 폴더에 PDF 저장 | `Ctrl+E` | `{출력폴더}\{고객사}\{도번}_Rev{리비전}_{날짜}.pdf` |

**다음 제품을 만드는 가장 빠른 방법**
비슷한 제품의 `.spec.json` 을 열고 → `파일 → 다른 이름으로 저장` →
고객사/정격전류를 바꾸고 `[도번 자동 생성]` → 값만 수정.

**파일 이름 규칙 바꾸기** : 출력 → 파일 이름 규칙
쓸 수 있는 항목 : `{도번}` `{리비전}` `{날짜}` `{발행일}` `{고객사}` `{제품명}`

## 7. 항목 늘리고 줄이기

왼쪽 목록 아래에서 종류를 고르고 `추가` 를 누릅니다.

| 종류 | 쓰임 |
|---|---|
| 본문 항목 | 글로 쓰는 지시사항 (조립 순서, 검사 항목 등) |
| 사양표 | 항목 / 사양 / 비고 표 — 가장 많이 씁니다 |
| 도면/그림 | 도면만 크게 넣을 때 (외형도 등) |
| 판수관리표 | 개정 이력 |

- `복제` : 비슷한 항목을 만들 때 (예: 요크 코어 → 복제 → 다리 코어)
- `▲` `▼` : 순서 변경
- **번호(1. 2. 3. …)와 PAGE n/N 은 항상 자동으로 다시 매겨집니다.**
- `이 항목부터 새 페이지` 를 켜면 그 항목이 새 장에서 시작합니다.

우리 회사 표준 구성이 정해지면
`파일 → 현재 문서를 템플릿으로 저장` 해 두고 다음부터 그걸로 시작하세요.
